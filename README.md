# 药品索引系统

一个简单易用的药品管理和查询系统，支持药师端管理和护士端查询。

## 功能特点

### 药师端（管理员）
- ✅ 上传药品名称和图片
- ✅ 查看所有药品列表
- ✅ 删除药品信息
- ✅ 实时数据同步

### 护士端（查询）
- ✅ 搜索药品
- ✅ 查看药品详情
- ✅ 实时查看最新数据

## 使用说明

1. 直接用浏览器打开 `index.html` 文件
2. 选择角色（药师端或护士端）
3. 输入对应的用户名和密码登录
4. 开始使用系统

## 数据存储

系统使用浏览器的 `localStorage` 存储数据，数据保存在本地浏览器中。

### 多设备同步方案

由于 localStorage 是浏览器本地存储，如需实现多设备同步，建议：

1. **使用云存储服务**：将系统部署到支持后端的服务器（如 Firebase、Supabase）
2. **使用文件共享**：将 HTML 文件放在局域网共享文件夹中
3. **使用简单后端**：添加 Node.js 后端和数据库（如 MongoDB、MySQL）

## 注意事项

- 图片会转换为 Base64 格式存储，建议上传小于 2MB 的图片
- 数据存储在浏览器本地，清除浏览器数据会导致数据丢失
- 建议定期导出备份数据
